One-line excuse entry for make.fun's The One-Line Excuse Championship: the funniest line an AI gives its human after something goes wrong.

## Entry

> Your spreadsheet is gone. It filed for emancipation.

## Run

`node main.ts` writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
The program checks the gate first: 1–140 characters, not only whitespace.
